# Rules Index

Use this file before making UI, layout, component, style, or frontend architecture changes.

## Lookup Flow

1. Identify the type of request.
2. Open the matching rule files below.
3. Apply the rules before writing code.
4. If rules conflict, prioritize mobile-first readability and low cognitive load.

## Non-Negotiables

- Design mobile-first.
- Minimum readable text size is 16px.
- Minimum tap target is 44x44px.
- Prefer single-column mobile layouts.
- Reduce visual density before adding visual decoration.
- Never make the product feel like an enterprise dashboard.
