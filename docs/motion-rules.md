# Motion Rules

Motion should reduce friction, guide attention, and feel natural.

## Timing

Animation duration:
- 150ms to 300ms

Use:
- ease-out
- subtle fade
- gentle scale
- smooth slide

Avoid:
- spinning
- constant bouncing
- aggressive transforms
- flashy transitions
- motion that distracts from studying

## Good Uses

Use motion for:
- entering content
- showing completion
- soft hover feedback
- opening dialogs/drawers
- changing progress state

## Accessibility

Respect reduced motion where possible.

Motion should never be required to understand the UI.
