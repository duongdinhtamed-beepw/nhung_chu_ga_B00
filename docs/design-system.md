# Design System

This project should feel like Notion plus Duolingo plus Apple Education: calm, friendly, focused, and easy to use on phones.

## Personality

The UI should be:
- soft
- airy
- lightweight
- emotionally welcoming
- modern
- student-centered

## Visual Direction

Prefer:
- generous whitespace
- rounded corners
- clear hierarchy
- simple cards
- pastel accents
- friendly empty states
- calm progress feedback

Avoid:
- enterprise dashboards
- dense metric grids
- heavy admin layouts
- harsh contrast
- neon palettes
- decorative complexity
- tiny controls

## Layout Style

Home:
- hero section
- daily progress
- study cards
- quick actions
- calm spacing

Study page:
- single-column mobile layout
- sticky bottom actions when helpful
- large readable content
- focus mode

Dashboard:
- progress cards
- soft charts
- minimal metrics
- motivational UI

Do not build dashboard screens like enterprise admin products.

## Density Rule

If a screen feels visually busy, reduce density by 40 percent before adding more decoration.

## Final Check

Ask:
- Is it readable on a phone?
- Is the main action obvious?
- Does the screen feel calm?
- Can a student use it without feeling overwhelmed?
