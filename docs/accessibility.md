# Accessibility Rules

Accessibility is part of the calm study experience.

## Always

Always:
- use semantic HTML
- maintain strong readability
- ensure touch friendliness
- support keyboard navigation
- keep focus states visible

Minimum tap size:
- 44x44px

Minimum primary text size:
- 16px

## Forms

All inputs must:
- have labels
- have visible focus states
- describe errors clearly

Do not rely only on placeholder text.

## Color

Never rely only on color.

Use labels, icons, text, or structure to communicate state.

## Motion

Avoid motion that can distract or disorient.

Support reduced motion where possible.
