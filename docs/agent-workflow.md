# Agent Workflow

Use this workflow whenever an AI agent changes this project.

## Before Coding

1. Read `CLAUDE.md`.
2. Read `docs/rules-index.md`.
3. Open the rule files that match the request.
4. Inspect existing components and styles.
5. Make the smallest maintainable change that satisfies the request.

## During Coding

Always:
- preserve the calm educational style
- keep UI mobile-first
- reuse existing components where possible
- keep spacing consistent
- avoid enterprise dashboard patterns

## After Coding

Check:
- mobile readability
- tap target size
- obvious primary action
- visual calmness
- accessibility basics
- maintainable component boundaries

If a change introduces a new pattern, document it in the relevant `docs/` file.
