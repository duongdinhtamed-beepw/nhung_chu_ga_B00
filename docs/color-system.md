# Color System

Use a soft, bright educational palette. Colors should support clarity and emotional safety.

## Tokens

Primary background:
- `#FAFBFC`

Card background:
- `#FFFFFF`

Soft blue:
- `#DCEEFF`

Soft violet:
- `#E9E4FF`

Soft green:
- `#DFF7E8`

Soft yellow:
- `#FFF4D6`

Text primary:
- `#1F2937`

Text secondary:
- `#6B7280`

Border:
- `#E5E7EB`

## Usage

Use background colors as gentle accents, not as visual noise.

Prefer:
- white cards on `#FAFBFC`
- soft pastel highlights
- text with strong readability
- subtle borders

Avoid:
- neon colors
- harsh gradients
- low contrast text
- too many accent colors on one screen

Never rely only on color to communicate meaning.
