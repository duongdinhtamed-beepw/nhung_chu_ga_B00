# AI Development Rules

You are building a calm educational platform for students.

The product must feel:
- soft
- lightweight
- emotionally safe
- welcoming
- mobile friendly
- modern

The interface should reduce stress and cognitive overload.

## UI Philosophy

Always prioritize:
1. readability
2. spacing
3. simplicity
4. focus
5. touch friendliness

Prefer:
- whitespace
- large typography
- rounded UI
- subtle shadows
- simple layouts

Avoid:
- clutter
- enterprise dashboards
- tiny UI
- dense layouts
- excessive gradients
- cyberpunk aesthetics

## Mobile First

Everything must be designed mobile-first.

Requirements:
- large tap targets
- stacked layouts
- responsive by default
- readable without zooming
- minimum text size: 16px
- comfortable spacing

## Design Style

Inspired by:
- Apple Education
- Notion
- Duolingo
- Headspace

Use:
- rounded-2xl
- rounded-3xl
- pastel accents
- airy spacing
- subtle animations

Avoid:
- sharp corners
- harsh contrast
- neon colors
- information overload

## Component Rules

Buttons:
- large
- touch friendly
- rounded-2xl
- soft hover states

Cards:
- spacious
- minimal
- softly elevated

Inputs:
- large
- readable
- obvious focus states

## Animation Rules

Animations must:
- feel smooth
- be subtle
- improve clarity
- never distract

Prefer:
- fade
- gentle scale
- soft slide

Avoid:
- excessive bouncing
- aggressive motion
- flashy transitions

## Development Rules

Use:
- Next.js App Router
- TypeScript
- TailwindCSS
- shadcn/ui
- Framer Motion

Prefer reusable components.

Keep components:
- modular
- readable
- maintainable

## Layout Rules

Prefer:
- single-column mobile layouts
- clean hierarchy
- large spacing rhythm

Avoid:
- nested complexity
- crowded dashboards
- excessive sidebars

Whitespace is important.

## Final Goal

The final UI should feel like:

"a peaceful digital study space for students."
