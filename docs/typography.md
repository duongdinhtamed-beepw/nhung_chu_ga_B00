# Typography

Typography should make studying feel calm and readable.

## Font Recommendations

Prefer:
- Inter
- Geist
- SF Pro
- Nunito

## Headings

Headings:
- font-weight: 700
- tracking: -0.02em
- clear hierarchy
- enough spacing from surrounding content

## Body Text

Body text:
- line-height: 1.7
- minimum size: 16px
- short readable sections
- avoid dense paragraphs

## Mobile Reading

On mobile:
- avoid cramped text blocks
- keep line length comfortable
- use spacing to separate ideas
- make labels and helper text readable

## Avoid

Avoid:
- text smaller than 16px for primary reading
- overly tight line height
- huge headings inside compact cards
- decorative type that hurts readability
