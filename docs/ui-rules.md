# UI Rules

Build mobile-first, calm, student-friendly screens.

## Tailwind Preferences

Prefer:
- `gap-4`
- `gap-6`
- `p-4`
- `p-6`
- `rounded-2xl`
- `rounded-3xl`
- `shadow-sm`
- `border`

Avoid:
- tiny spacing
- excessive nested flex
- visual noise
- crowded controls
- dense tables as a default pattern

If unsure, choose simpler UI.

## Buttons

Buttons should be:
- large
- touch friendly
- at least 44x44px
- rounded-2xl
- visually clear
- calm on hover/focus

Use icons for obvious tools and commands when useful.

## Cards

Cards should be:
- spacious
- minimal
- softly elevated
- easy to scan

Use cards for individual repeated items, tools, and modals. Do not nest cards inside cards.

## Inputs

Inputs should:
- have visible labels
- be readable
- have obvious focus states
- be easy to tap on mobile

## Layout

Prefer:
- single-column mobile layouts
- clear section rhythm
- obvious primary action
- quiet secondary actions

Avoid:
- excessive sidebars
- dense dashboard grids
- complex nested layouts
- developer-tool aesthetics

## Common Fix Prompts

When UI is too dense:
- Reduce visual density by 40 percent.

When UI is desktop-first:
- Rebuild this screen mobile-first.

When UI feels too technical:
- Make this feel more like a modern educational app and less like a developer tool.

When spacing is tight:
- Increase spacing and breathing room throughout the layout.
