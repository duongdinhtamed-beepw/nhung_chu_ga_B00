# Components

This folder is organized for calm, mobile-first educational UI.

Use:
- `components/ui` for UI primitives and shadcn/ui components
- `components/layout` for shells, containers, navigation, and sticky actions
- `components/study` for lesson, quiz, practice, and focus-mode components
- `components/cards` for reusable study and progress cards
- `components/animations` for shared motion helpers

Before adding components, read:
- `docs/component-guidelines.md`
- `docs/ui-rules.md`
- `docs/accessibility.md`
