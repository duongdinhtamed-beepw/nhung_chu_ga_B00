# AI Development Rules For Web Hoc

This project is a calm educational platform for students.

Before creating or changing UI, AI agents must read the relevant rules in
`docs/rules-index.md`, then follow the linked documents for the requested work.

Core product feeling:
- soft
- lightweight
- emotionally safe
- welcoming
- mobile friendly
- modern

Primary rule:
The final UI should feel like a peaceful digital study space for students.

Always prioritize:
1. readability
2. spacing
3. simplicity
4. focus
5. touch friendliness

Avoid:
- enterprise dashboards
- dense admin screens
- tiny text
- clutter
- harsh contrast
- neon/cyberpunk styling
- excessive gradients

Default stack:
- Next.js App Router
- TypeScript where possible
- TailwindCSS
- shadcn/ui when available
- Framer Motion for subtle transitions
- Lucide icons for common actions

When uncertain between fancy and simple, choose simple.
